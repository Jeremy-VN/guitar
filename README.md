# Jeremy's Guitar

A small static site — no build step, no dependencies, nothing to install.
Everything runs in the browser and works offline once a page has loaded.

Live at: **https://jeremy-vn.github.io/guitar/**

## Layout

```
index.html            the contents page — generated, don't hand-edit
lessons/
  index.html          dated lesson list — generated, don't hand-edit
  YYYY-MM-DD-slug.html   one self-contained lesson (audio embedded as data URIs)
practice/
  index.html          practice tools hub
  fretboard-trainer.html   name-the-note / find-the-note, click or play into the mic
  ear-trainer.html         intervals, chord quality, scale degrees, hear-it-find-it
  how-to-practise.html     the learning-science review behind the drill design
  samples/            37 chromatic guitar notes, D2–D5 (University of Iowa, mono 96 kbps)
reference/
  index.html          fretboard map, octave shapes, unisons, capo table — all generated
lessons.json          the lesson manifest — this is the file you edit
build_index.py        regenerates index.html and lessons/index.html from lessons.json
```

`index.html` and `lessons/index.html` are **both** generated by `build_index.py`.
Edit `lessons.json`, run the script, commit the result.

## Add a lesson

1. Drop the lesson HTML into `lessons/` as `YYYY-MM-DD-slug.html`.
2. Add a block to `lessons.json` (`file` stays repo-relative, e.g. `lessons/2026-08-15-topic.html`).
3. `python3 build_index.py`
4. Commit and push. GitHub Pages redeploys in about a minute.

## Publishing

The site needs no credentials to run — GitHub Pages serves it straight from this repo.
A token is only needed at the moment of a push. Use a **fine-grained** personal access
token restricted to this repository with **Contents: Read and write** (Metadata: Read-only
is added automatically and is mandatory). A classic `repo`-scope token would grant access
to every repository on the account, which this task does not need.

The Pages URL is case-sensitive: **/guitar/**, not /Guitar/.

## Notes

- **The microphone mode needs HTTPS.** It works on the live site; it will not work
  from a downloaded copy opened off the local disk.
- **The guitar samples need to be served alongside the pages.** Opening a trainer as a
  standalone file falls back to the built-in synth and says so.
- Practice stats are kept in browser local storage, per device. Nothing is uploaded anywhere.
- Public repo, so anyone with the URL can read it. Nothing personal is stored here.
